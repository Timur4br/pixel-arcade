## Minecraft и локальная библиотека

Оригинальные записи Minecraft не загружены в репозиторий. [Официальное разрешение на музыку относится к контенту по Minecraft](https://www.minecraft.net/en-us/article/can-i-use-minecraft-music-); автоматического разрешения для нашего игрового каталога не найдено. Поэтому новая тема меню — самостоятельная атмосферная композиция, без цитирования мелодий C418.

Для личного прослушивания можно выбрать свои аудиофайлы с устройства. Они сохраняются локально и не отправляются на GitHub. Для публичного включения чужих записей потребуется подходящее разрешение правообладателей.
