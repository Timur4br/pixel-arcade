# Пиксель

Браузерный каталог игр и алгоритмических задач. Работает без сервера: открой index.html или сайт GitHub Pages.

## Как работает

Выбери задачу и режим: **Играть** — ручное решение, **Смотреть бота** — автоматическое выполнение. В задачах №1–10 есть пауза, один шаг бота, три готовых уровня и редактор. Свой уровень можно сохранить в браузере. Формулировка из PDF открывается внутри задачи.

Алгоритмы отделены от интерфейса: algorithms.js — правила и решатели, course-ui.js — отображение, course-levels.js — уровни и проверка данных. Для мудрецов используются пять Web Workers и координатор вилок. Перевозки решаются потоком минимальной стоимости, пути — поиском в ширину, башни — рекурсией. Бот жучка ищет непрерывный обход без повторных клеток; для сложных своих областей перебор ограничен. Раскраска Ершова — эвристика объединения вершин второй окрестности, без гарантии минимума цветов.

## Дополнительные игры

Сохранены первые пять: Змейка, Пинг-понг, Крестики-нолики (3×3), 2048, Найди пару. Их рекорды хранятся на устройстве. Вариант крестиков-ноликов №37 с произвольным полем пока в плане.

## Запуск и публикация

- Локально: открыть index.html. Для Web Workers предпочтителен сайт или node server.cjs → http://localhost:4173.
- GitHub Pages: загрузить содержимое папки в корень репозитория; Settings → Pages → Deploy from a branch → main → / (root) → Save.
- Проверки с Node.js: node --test tests/*.test.cjs.
