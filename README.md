# Пиксель

Пять игр в браузере: Змейка, Пинг-понг, Крестики-нолики, 2048 и Найди пару. Каталог разделён по жанрам. Каждая игра поддерживает ручной режим и наблюдение за ботом, паузу и перезапуск. Управление адаптировано для клавиатуры, мыши и сенсорного экрана. Рекорды ручного режима хранятся в localStorage этого браузера.

## Запуск

Откройте `index.html` в современном браузере. Сборка и установка зависимостей не нужны. При отсутствии интернета используются системные шрифты.

Для локального HTTP-просмотра с установленным Node.js:

```sh
node server.cjs
```

Откройте http://localhost:4173. Проверка правил: `node --test tests/rules.test.cjs`.

## Публикация через GitHub Pages

1. Создайте репозиторий на GitHub и загрузите **содержимое** этой папки в корень, включая `.github/workflows/pages.yml`. Не загружайте ZIP вместо исходников.
2. Основная ветка должна называться `main`.
3. В Settings → Pages → Build and deployment выберите Source: **GitHub Actions**. Доступность Pages зависит от тарифа и видимости репозитория.
4. Откройте Actions → Publish GitHub Pages → Run workflow (или отправьте новый коммит в main).
5. После успешного выполнения ссылка появится в Settings → Pages и в результатах workflow. Последующие коммиты в main публикуются автоматически.

Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## Боты

- Змейка: оценка свободной области заливкой и расстояния до еды; бот может проиграть. Края поля соединены.
- Пинг-понг: ракетка следует за мячом с ограничением скорости; матч до 7 очков.
- Крестики-нолики: полный минимакс; оптимальный бот не проигрывает.
- 2048: эвристика свободных клеток, объединений и размещения крупных чисел; победа не гарантируется.
- Найди пару: бот запоминает только открытые карточки и использует известные пары.

Нейросетей, внешних API и сервера в играх нет. Рекорды бота не подменяют личные рекорды.

## Структура и развитие

`index.html` — интерфейс, `style.css` — оформление, `engine.js` — чистые игровые правила, `app.js` — каталог, состояние и игровые экраны. Для следующей игры добавьте запись в `games`, инициализацию, отрисовку и обработку хода/бота. Шрифты опционально загружаются с Google Fonts; остальные ресурсы локальные.

Текущая версия не включает учётные записи, сетевой мультиплеер или общую таблицу рекордов.
