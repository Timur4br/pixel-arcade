# Пиксель

42 задания из методички и 5 дополнительных игр. Работают в браузере без регистрации и установки.

## Как играть

Выбери игру по жанру или найди её по названию / номеру. **Играть** — ручное управление, **Смотреть бота** — автоматическое прохождение. Есть пауза, перезапуск, скорость и один шаг бота. У каждого задания — три варианта уровня, формулировка из PDF и редактор параметров. Свои параметры сохраняются в этом браузере.

В редакторе меняются `variant` (0–2), `seed` и параметры конкретной игры: текст поиска, массив сортировки, размер поля, длина ряда, список слов, число мин и другие. Подсказки находятся рядом с редактором. В первых десяти задачах доступен редактор исходных данных, у сеточных задач — также правка клеток.

## Варианты правил

Покер — обмен пяти карт и сравнение комбинаций, без ставок. «Посадка на луну», «Танчики», Bomber, Space Invaders и «Лемминги» — самостоятельные компактные версии. Читатели/писатели и производители/потребители показывают работу очередей и синхронизации как пошаговые модели; обедающие мудрецы используют Web Workers. Бот «Вампуса» знает карту; бот «Сапера» видит только открытые числа и может проиграть при угадывании. Для сложных поисковых задач есть лимит перебора.

## Дополнительные игры

Сохранены Змейка, Пинг-понг, Крестики-нолики 3×3, 2048 и Найди пару. Их рекорды хранятся на устройстве. В №37 отдельно доступны нечётные поля 3–11 клеток с заданной длиной победного ряда.

## Запуск

- Открой `index.html`. Для Web Workers предпочтителен сайт или `node server.cjs` → http://localhost:4173.
- GitHub Pages: загрузи содержимое папки в корень репозитория. Settings → Pages → Deploy from a branch → main → / (root) → Save.
- Проверки: `node --test tests/*.test.cjs`.
