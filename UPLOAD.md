# Как обновить сайт

1. Распакуй архив.
2. Открой https://github.com/Timur4br/pixel-arcade — вкладка Code, ветка main, корень репозитория.
3. Add file → Upload files. Перетащи **index.html из этого архива**.
4. Нажми Commit changes. Дождись завершения публикации Pages во вкладке Actions.
5. Открой https://timur4br.github.io/pixel-arcade/ и нажми Ctrl+F5.
6. Внизу должно быть: «пиксель.», «by t4br», «v0.7.0-alpha».

Для запуска нужен только этот index.html: код, стили и картинки уже встроены. Остальные файлы можно оставить как есть. Исходники в архиве нужны для дальнейшей разработки; после их изменения запускай node tools/build.cjs.

Причина прошлой поломки: в репозитории были обновлены 104 файла, но оставлен index.html версии 4. Он не подключал release-ui.js, release-models.js и release.css, поэтому редакторы прерывали запуск игр и оставляли незакрытые панели.
